# 桌球自動發球機精準落點與四參數智慧控制模型

## 啟動

下列步驟已在 Python 3.14 驗證。在專案根目錄開啟 PowerShell 並執行下列指令。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --workers 1
```

在瀏覽器開啟 [http://127.0.0.1:8000](http://127.0.0.1:8000)。已安裝相依套件時可直接執行 `python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --workers 1`。使用單一服務程序，讓服務共用同一份任務與模型狀態。結束時在終端機按 `Ctrl+C`。

## 使用方式

1. 在「模型訓練」選擇三份 `.xlsx`，確認檔案清單後按「啟動訓練」。每次訓練使用當次選取的檔案，檔名可自行決定。
2. 等待資料驗證、五折訓練、選模、正式重訓及保存。完成後可查看各折與平均 Macro F1、X／Y 勝出模型、命中率、有效性矩陣、整球判對比例和平均距離。
3. 在「單球預測」輸入四參數。實測欄可選未填、有效球或無效球。有效球要輸入 X、Y，雙方皆有效時計算距離。預測有任一軸為 0 時顯示「無效球」與原始座標。

## Excel 格式

每份檔案至少要有一張資料表。資料表的第一列須有下列 10 個欄位，順序可調整。

| 欄位 | 格式 |
| --- | --- |
| 測試編號 | 原始紀錄編號，供回查 |
| 仰角角度 | 整數 1～28 |
| 左右位置 | 整數 1～9 |
| 旋球角度 | 整數 1～59，為發球機旋球設定值 |
| 出球強度 | 整數 1～99 |
| 發球1_落點 至 發球5_落點 | 半形座標 `(x,y)`，x、y 為 1～5 的整數，或指定無效文字 |

空白列依四參數及五個落點判定。其餘列若有非法參數，訓練會停止並指出原始位置。等於整數的數值（含可精確解析的數字文字如 `13.0`）可用。落點允許首尾及座標內空白。「碰桌後彈出」「飛出台面」「未過網」「球碰網後沒有進入有效區」計為無效球 `(0,0)`。空白、字面 `(0,0)`、混合零座標與其他無法辨識的原始落點都計為缺測。

## 資料與成果

系統會在 `data/uploads/<run_id>/` 保存上傳的活頁簿與原檔名對照。已發布的 `data/artifacts/<run_id>/` 包含兩個正式模型、`fold_predictions.csv` 與 `report.json`。同一批成果完成保存後才更新 `latest_success.json`。新任務執行中或失敗後，已有的正式模型與對應報表仍可使用。服務重啟時會載入最近成功發布的批次。
